# Changelog

All notable changes to the `api-contract` plugin. Follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-10-03

### Added

- `breaking-change` skill — removal, rename or narrowing of a public contract.
- `response-schema` skill — response shape changes (types, optional/nullable, enums, wrapping, status codes, data exposure).
- `semver-discipline` skill — required MAJOR/MINOR/PATCH bump vs the declared one.
- `deprecation-policy` skill — deprecate → keep working → remove, instead of silent deletion.
